# Security Policy

## Supported Versions

The following versions of `@misabegovic/pi-brain` are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3   | :x:                |

## Reporting a Vulnerability

If you discover a security issue, please email the maintainer directly at the address associated with the package author. Do not open a public issue until the vulnerability has been addressed.

You can expect an initial response within 7 days. We will coordinate a fix and disclosure timeline with you.
